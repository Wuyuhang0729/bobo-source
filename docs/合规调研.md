# 合规调研：这类第三方音源会被哪些规范禁止

> 整理时间：2026-10-07。本文是**条款原文与公开判例的整理**，不构成法律意见。
> 结论一句话：**使用本项目会违反平台用户协议**（条款是明确写着的，不是"可能"）；
> 是否进一步构成不正当竞争 / 规避技术措施，取决于使用方式与分发方式。

## 一、适用的协议

波点音乐由**北京酷我科技有限公司**运营（属腾讯音乐娱乐集团 TME），因此适用于酷我 / TME 的用户协议。

| 条款 | 要点 | 来源 |
|---|---|---|
| 酷我协议 **2.1** | 禁止反向工程、反向编译、反向汇编；不得改动编译在程序文件内部的任何资源 | [酷我客服页](http://www.kuwo.cn/static/page/customer/customerservice.html) |
| 酷我协议 **2.5 个别授权** | 任何组织或个人利用软件产品以任何方式为公众服务并分发、复制、传播，须经酷我授权，否则视为侵权 | 同上 |
| 酷我协议 **5.1.7 (2)** | 不得反向工程、反向汇编、反向编译或以其他方式尝试发现软件源代码 | [酷我用户服务协议](http://2496.kuwo.cn/regterm.html) |
| 酷我协议 **5.1.7 (4)** | 不得对客户端与服务器端的交互数据进行复制/修改/挂接或**创作任何衍生作品**，形式包括使用插件、外挂或**非经合法授权的第三方工具/服务接入软件和相关系统** | 同上 |
| 酷我协议 **5.1.7 (6)** | 不得**通过非酷我开发、授权的第三方软件、插件、外挂、系统，登录或使用软件及服务，或制作、发布、传播上述工具** | 同上 |
| **TME 服务协议 10.4** (2)(4)(6) | 与上述平行的反向工程 / 非授权第三方工具接入 / 制作发布传播条款 | [TME 服务协议](https://www.tencentmusic.com/zh-cn/protocol.html) |

违反后果（协议原文）：终止服务、回收账号、保留追究法律责任的权利。

## 二、本项目行为的对照

| 协议禁止的行为 | 本项目 | 是否落上 |
|---|---|---|
| 反向工程、尝试发现源代码 | 接口签名算法、端点、参数均由逆向所得 | ✅ |
| 使用非授权第三方工具接入 / 登录使用其服务 | 模组即第三方工具，且支持账号登录 | ✅ |
| 制作、发布、传播上述第三方工具 | 本仓库公开分发 | ✅ |
| 对交互数据创作衍生作品 | 解析接口响应并在播放器展示 | ⚠️ 边缘 |
| 篡改客户端、绕过服务端校验 | **没有做**（不修改 App、不伪造请求绕过权限校验） | ❌ |
| 存储 / 转存 / 解密音频 | **没有做**（只解析播放地址交给播放器） | ❌ |

## 三、相关判例（都不是针对本项目，但形态相近）

| 案件 | 行为 | 结果 |
|---|---|---|
| **「发条」APP**（涉 QQ音乐、网易云音乐） | 内嵌浏览器播放、**屏蔽官方按钮**、关联账号导入歌单、**"复活 VIP 歌单"** | 认定不正当竞争，**判赔 80 万**，二审维持 |
| **咪咕音乐 vs 虾米音乐**（四川高院 (2021)川知民终2216号） | 在自家 APP 内**嵌入歌曲音源 URL 实现盗链**，18 万首 | 判赔 **150 万**；适用《反不正当竞争法》**第二条**一般条款 |

法条适用规律：盗链/设链/内嵌跳转类多走**第二条**；一旦涉及**绕过登录或付费机制、屏蔽按钮**
（即"妨碍、破坏服务正常运行"），更倾向**第十二条**互联网专条（第 2 款第 4 项兜底）。

> 检索中**未发现以酷我为原告、针对第三方客户端的具名判决**。

## 四、本项目与判例的差别（减轻因素）

- **无竞争关系、无商业目的**：本机播放器的一个插件，不做竞品、不引流、不获利 ——
  反不正当竞争法的适用前提（竞争关系 + 争夺商业利益）较弱；
- **不篡改客户端**：不修改 App 二进制、不绕过服务端权限校验；
- **不屏蔽官方入口**：不像「发条」那样屏蔽官方按钮；
- **不用匿名通道取整曲**：`ALLOW_CAR_CHANNEL` 默认关闭，取址只用使用者自己账号的权益；
- **不落盘音频**：不存储、不转存、不解密。

## 五、已经做的降险措施

1. 匿名车机通道（无需登录即可拿整曲 / FLAC）**默认关闭**；
2. 未登录时只使用官方给匿名的试听能力；
3. README / NOTICE 写明非官方、无关联、风险自担；
4. 仓库内不含任何凭据（`.env`、token、cookie 一律不入库，历史中也从未有过）。

## 六、信息缺口（别当已核实）

  （篡改客户端 + 绕过服务端校验）。本项目**没有**这类行为。

## 七、结论

- **自用（不公开、不传播）**：属协议违约范畴，实践中风险很低。
- **公开分发**：确实违反平台协议，存在被主张不正当竞争或收到下架 / 律师函的现实可能，
  但鉴于上述减轻因素，量级明显低于判例中的情形（判例均含商业目的与竞争关系）。
- 若收到权利人异议：**先配合下架**，保留提交历史作为证据。
