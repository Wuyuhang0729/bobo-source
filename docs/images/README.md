# 演示图（GIF）

README 里展示功能的动图放这里。文件名先定好，插引用时直接按这个名字写。

## 需要哪几张

| 文件名 | 录什么 | 建议尺寸 | 体积目标 |
|---|---|---|---|
| `enable-mod.gif` | 设置 → 系统 → 模组 → 启用「波点音乐」→ 系统确认弹窗 | 1100×700 | < 2 MB |
| `login-qr.gif` | 首页平台切到波点 → 点账号区域 → 扫码弹窗 | 900×650 | < 2 MB |
| `playlists.gif` | 歌单页：卡片网格滚动 → 点开一个歌单 → 曲目列表 | 1100×700 | < 3 MB |
| `search.gif` | 搜索：输入关键词 → 歌曲 +「歌单」分区 → 点「加载更多」→ 点开一个歌单 | 1100×700 | < 3 MB |
| `now-playing.gif` | 播放页：逐字歌词效果（换一两个视觉模式更好看） | 1100×700 | < 4 MB |

## 录制参数（ScreenToGif）

- **只框选界面主体**，别录整屏 1920×1080 —— 体积会翻好几倍。
- 帧率 **10–15 fps**，单段时长 **5–10 秒**（够展示一个完整动作就行）。
- 导出前用它自带的优化器：`Reduce frame count` + `Reduce color depth`（128 色足够）。
- 目标：**单张 < 3 MB**；超过 5 MB 就缩短时长或把区域裁得更小。

## 隐私（录之前先扫一眼）

可能入镜的敏感内容：

- 右下角的**账号昵称**；
- 「我的歌单」里的**私人歌单名**（那是账号里的数据）；
- 扫码登录的**二维码**（有时效，但没必要留痕）。

建议：录制区域**裁掉右下角**；登录那段只录弹窗出现、不等二维码刷新；歌单页可以改录"搜索出来的平台歌单"（那些是公开内容，创作者也不是你）。

## 可选：用 ffmpeg 再压一次

ScreenToGif 自带的优化一般够用。还想更小：

```powershell
winget install Gyan.FFmpeg     # 需要完整版；folia 自带那份是精简构建，没有 gif 编码器
pwsh tools/optimize-gif.ps1 docs\images\search.gif -Width 900 -Fps 10
```

输出为 `search-opt.gif`（不覆盖原文件），并打印省了多少百分比；满意后再改回原名。
